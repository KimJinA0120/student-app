# 수강생 관리 사이트 요구사항

Oct 29, 2026 · @진아 (10/29 근무 중인 강사 패널 제거·강사 시간표 반영)

## 개요

운영 매니저들이 강사 근무·수업 진행·수강생·매니저 근무 정보를 한곳에서 관리하는 내부용 사이트다. 수강생 출석은 별도 사이트에서 하며, 이 사이트는 운영 관리 용도로만 쓴다. **약 1달 쓰는 단기 시스템이므로 기능은 최소로 유지한다.**

| 항목 | 내용 |
| --- | --- |
| 사용자 | 운영 매니저 약 10명 (현재 7명), 하루 3~4명 접속 |
| 관리 대상 | 수강생·강사·매니저 합계 100~300명 내외 |
| 사용 환경 | PC (서버 PC + 매니저 개인 노트북) |
| 사용 기간 | 약 1달 (강사 일정 기준 10/27~12/10) |
| 배포 | 인터넷 배포 없음, 교육센터 내부망 전용 |
| 수업 교시 | 1교시 09:30~12:00 · 2교시 13:00~15:30 · 3교시 15:30~18:00 · 4교시 19:00~21:30 |
| 교실 | 8개 (평소 7개 운영) |
| 로그인 · 작성자 | 둘 다 없음 |

## 운영 방식

- 수업 = 강사 1명 + 수강생 1명 이상. 1명이 듣든 여러 명이 듣든 같은 "수업"으로 다루며, 팀/개인 수업을 구분하지 않는다.
- 수강생이 오면 지금 근무 중이면서 수업 중이 아닌 강사와 빈 교실을 골라 수업을 시작한다.
- 강사별로 정해진 교실은 없다. 빈 교실을 그때그때 사용한다.
- 주강사·보조강사 모두 강의한다.

## 시스템 구성

센터 PC 한 대에서 서버를 실행하고, 매니저들은 내부망 주소로 접속한다. 데이터는 서버 PC의 H2 데이터베이스 파일에 저장한다. (기술 상세는 설계 문서 참고)

- **접속:** 서버 PC는 `localhost:3000`, 다른 노트북은 `서버 PC 내부망 IP:3000`.
- **조건:** 사용 시간 동안 서버 PC가 켜져 있어야 한다.

## 수업 기록

**폼 여는 방법 (4가지)**

1. 상단 [수업 기록] 버튼 → 빈 폼
2. 강사 탭 시간표 칸의 [수업시작] → 강사·날짜·교시가 채워진 폼 (강의실은 빈 교실 자동 배정)
3. 수강생 탭 목록에서 체크박스로 수강생 선택 → 검색바 옆 [수업시작] → 선택한 수강생이 채워진 폼 (여러 명이면 한 수업에 함께 들어감)
4. 수강생 상세 화면의 [수업시작] → 그 수강생이 채워진 폼

**폼 항목**

| 항목 | 형식 |
| --- | --- |
| 수강생 | 수강생 목록에서 선택, 여러 명 가능 |
| 강사 | 근무 중인 강사 중 선택 (지난 기록 입력 시에는 전체 강사) |
| 강의실 | 빈 교실이 배정 순서대로 자동 매칭됨, 변경 가능 |
| 날짜 · 교시 | 현재 값으로 자동 입력, 수정 가능 |
| 시작 · 종료 시각 | 선택 사항. 비우면 교시 시간으로 본다 |

**희망 강사 알림**

- 수강생이 1명이고 희망 강사가 있을 때만 띄운다.
- 희망 강사 중 지금 근무 중이고 수업 중이 아닌 강사가 있으면 "OO 강사님이 수업하나요?" → [예] 강사 칸 자동 입력 / [아니오] 직접 선택.
- 희망 강사가 모두 부재이거나 수업 중이면 알림 대신 "희망 강사 부재 / 수업 중" 안내만 표시한다.

**지난 기록**

- 현재 수기로 작성 중인 기록을 옮겨야 하므로, 지난 날짜·교시의 수업도 입력할 수 있고 수정·삭제할 수 있다.

## 강사 탭

기존 강사 일정 HTML의 데이터를 사이트로 한 번 옮겨오고, 이후에는 사이트에서 관리한다. 화면 모양은 HTML을 최대한 따르되, 내용은 요일이 아니라 **날짜 기준**(그날의 결근·추가 배치 반영)으로 보여준다.

**강사 정보**

- 이름, 연락처 (현재 31명)
- 요일·교시별 기본 배치와 역할 (주 / 보조). 역할은 표시용.

**날짜별 예외**

날짜 · 교시(비우면 전 교시) · 메모 단위로 입력한다.

| 종류 | 의미 | 예 |
| --- | --- | --- |
| 결근 | 기본 배치에 있지만 그날 불가 | 11/9 3교시 불가. 기간이 있으면 시작일·종료일로 한 번에 입력 |
| 조건부 | 확정은 아니지만 가능성 있음 | 11/16부터 전 교시, 해당 날짜 목록 + 메모 |
| 추가 배치 | 기본 배치에 없지만 그날만 확정 | 날짜별로 따로 받은 일정 |
| 메모 | 불가는 아니지만 그날 아래 표시 | 12/2 오후 1시간 정도 늦을 수 있음 |

**날짜별 보기 (기본)**

- 주 단위 이동 (이전 / 다음 주) + 월~일 탭, 탭에 실제 날짜 표시 (예: 11/2 월), 오늘 날짜로 열림, 날짜 선택 칸으로 바로 이동
- 강사 × 1~4교시 **시간표**. 이름 옆에는 주/보조만 표시한다 (연락처·기본 배치 비고는 강사 상세에서 본다). (10/29 변경)
- 표 머리에 교시별 인원과 부족 여부. 부족 기준 **8명**. (10/29 변경)
  - **총 인원 = 그 교시에 출근 가능한 인원 = 고정 + 조건부**. 부족도 총 인원으로 판정 ("총 6명 · 부족 2")
  - 그 아래 "고정 5 · 조건부 1 · 결근 2"로 나눠 보여 준다. 고정 = 확정 근무(결근·조퇴 반영 후), 결근 = 기본·추가 배치에 있었지만 그날 결근으로 빠진 강사
- 그날 빠지는 강사와 메모는 표 아래에 표시

**시간표 칸** (10/29 추가)

- 칸 = 그 강사·날짜·교시의 **예약** + **수업 기록** (강의실 + 수강생).
- 근무하는 칸(확정·조건부 "조")만 입력할 수 있다. 근무가 없는 칸·조퇴 후 칸은 회색으로 막는다.
- **명칭** (10/30): 자유 글 = **메모 예약**, 등록 수강생 고르기 = **예약**. 한 칸에 둘 다 둘 수 있다.
- **예약** (10/30 추가): 칸 맨 위 입력칸("예약")을 누르면 큰 창이 떠서 등록된 수강생을 체크한다 (이름 찾기·스크롤 목록).
  - [수업시작]을 누르면 예약 수강생이 수업 기록 폼에 미리 체크된다.
- **메모 예약** (10/29 추가): 미등록(첫 수업)·이름 모르는 수강생을 적어 두는 한 줄 글 ("김철수, 이영희" / "3명"). 칸 맨 아래 [수업시작]·[조퇴] 밑의 "메모" 입력칸.
  - Enter로 저장, 비우고 Enter면 메모만 삭제. 예약·메모가 모두 비면 칸이 빈다.
  - 수업 기록·방문 회차와는 별개. 그 칸에 수업 기록이 생기면 예약·메모는 숨긴다.
  - 지난 교시 칸은 고칠 수 없다. 근무가 빠진 칸은 "근무 없음 · 확인 필요"로 남기고 [삭제](예약·메모 모두)만 둔다.
- **미배정** (10/29 추가, 10/30 예약 추가): 강사를 정하지 않고 날짜·교시만 정해 오는 수강생용. 시간표 맨 위 "미배정" 줄에 교시마다 예약 + 메모를 둔다 (근무 여부와 상관없이 입력).
  - [배정]: 그 교시에 근무하는 강사를 골라 그 강사 칸으로 옮긴다. 그 칸에 이미 있으면 메모는 ", "로 이어 붙이고 예약 수강생은 합친다.
  - 강사와 연결이 없어 수업 기록이 생겨도 자동으로 숨기지 않는다. 배정 없이 수업을 시작했으면 [삭제]로 지운다.
  - 지난 교시 칸은 글 + [삭제]만 둔다.
- 버튼
  - [수업시작]: 수업 기록 폼을 강사·날짜·교시가 채워진 채로 연다. 아직 안 끝난 수업이 있는 칸에는 없고, 중간에 [종료]하면 다시 보인다. 지난 칸은 기록이 없을 때만 보인다 (수기 기록 옮기기용).
  - 수업마다 [추가] (수강생 추가) · [종료] (지금 진행 중일 때만, 종료 시각 기록) · [취소] (확인 후 삭제). 강의실·수강생을 누르면 수정 화면.
  - [조퇴]: 오늘, 아직 끝나지 않은 근무 칸에만. 누르면 그 교시까지 근무하고 이후 교시에서 빠진다. 누른 칸에는 "조퇴" + [취소]가 대신 보이고, [취소]하면 원래 근무로 되돌린다.
- 교시가 끝나면 수업은 자동으로 종료된다.

**이름 검색**

- HTML처럼 이름을 검색하면 그 강사의 일정만 날짜순으로 보여준다.

**전체 달력**

- PDF 양식처럼 10/27~12/10 전체를 월~일 달력으로 보여준다.
- 날짜 칸에 교시별 총 인원(고정 + 조건부) 숫자 + 강사 이름, 조건부 강사는 노란 점선으로 따로 표시, 칸 아래에 그날 메모.
- 숫자 색: 8명 이상 초록, 미만 주황. 주·보조·조건부 모두 포함. (10/29 변경)
- 날짜를 누르면 그 날짜의 날짜별 보기로 이동한다.

## 운영 매니저 탭 (기존과 동일)

- **매니저 정보:** 이름, 연락처 (약 10명까지 등록·추가)
- **기본 근무표:** 요일별 근무 시간 (예: 월 09:00~18:00)
- **예외:** 날짜 · 내용 (휴무 / 시간 변경)
- **날짜별 보기:** 주 단위 이동 + 요일 탭. 그날 근무자와 근무 시간, 휴무·시간 변경자.

## 교실

| 교실 | 구분 | 배정 순서 | 평소 운영 |
| --- | --- | --- | --- |
| 일반 교실 6개 | 일반 | 1순위 | 포함 |
| 상담실 | 상담실 | 2순위 | 포함 |
| 창고 겸용 1개 | 창고 겸용 | 3순위 (예비) | 미포함 |

- 교실 목록은 초기 데이터로 고정하며, 설정 화면은 두지 않는다.
- 수업 시작 시 그 교시에 비어 있는 교실을 배정 순서대로 자동 매칭하고, 폼에서 바꿀 수 있다.

## 확인 필요 (오른쪽 사이드 패널)

- 확인이 필요한 내용을 한 줄씩 적어 두는 목록. 관련 사람 이름을 함께 적을 수 있다.
- 해결되면 체크해서 목록에서 뺀다.
- 잘못 쓴 항목은 [삭제]로 지운다 (확인 후 삭제). 내용 수정은 두지 않는다 (해결 체크 후 새로 작성). (10/28 추가)
- 해결된 항목은 패널 아래 "해결된 항목 (n)"을 펼쳐 최근 해결순으로 다시 볼 수 있고, [되돌리기]로 남은 목록에 다시 넣을 수 있다. (10/28 변경)
- 패널은 접었다 펼 수 있다. 접으면 "확인 필요 (3)"처럼 남은 개수만 보인다. (10/28 추가, 달력·표 화면 폭 확보)
- 이름 옆 "!" 마크는 두지 않는다.

## 데이터 이전

- 강사: 강사 일정 HTML에서 이름·연락처·요일별 배치·결근·조건부·추가 배치·메모를 옮긴다. HTML의 "확인 필요" 항목은 사이드 패널 목록으로 옮긴다.
- 교실: 8개를 초기 데이터로 등록한다.
- 수강생·수업 기록·운영 매니저: 사용자가 사이트에서 직접 입력한다 (지난 수업 기록 포함).
