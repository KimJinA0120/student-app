# 수강생 관리 사이트 운영 매뉴얼 (매니저용)

운영 매니저가 사이트를 쓰는 방법을 정리한 문서다. 서버 PC 설치·백업·복구는 `운영 가이드.md`를 본다.

- **접속:** 매니저 노트북은 `http://서버 PC IP:3000` (예: `http://192.168.0.20:3000`), 서버 PC는 `http://localhost:3000`
- **로그인 없음.** 누가 입력했는지도 남지 않으니, 지우거나 고치기 전에 한 번 더 확인한다.
- 저장하면 바로 반영된다. 따로 [저장 완료] 같은 절차는 없다.
- 사용 기간: 10/27 \~ 12/10

---

## 1. 화면 구성

| 위치 | 내용 |
| --- | --- |
| 맨 위 | **[수업 기록]** 버튼 (어느 화면에서나 빈 수업 기록 폼을 연다) |
| 탭 | 강사 · 수강생 · 상담 · 운영 매니저 · 수업 기록 · 업무일지 |
| 오른쪽 | **확인 필요** 패널 (접으면 "확인 필요 (3)"처럼 남은 개수만 보인다) |

**교시**

| 교시 | 시간 |
| --- | --- |
| 1교시 | 09:30 \~ 12:00 |
| 2교시 | 13:00 \~ 15:30 |
| 3교시 | 15:30 \~ 18:00 |
| 4교시 | 19:00 \~ 21:30 |

- 쉬는 시간(12:00 \~ 13:00, 18:00 \~ 19:00)에는 **다음 교시**로 본다. 예: 12:30에 수업 기록을 열면 2교시가 채워진다.
- 교시가 끝나면 수업은 자동으로 끝난 것으로 본다. [종료]를 누르지 않아도 된다.

## 2. 하루 흐름 (요약)

1. **출근 후** 강사 탭 → 날짜별(오늘)에서 교시별 인원과 "부족" 표시, 표 아래 "빠지는 강사"·메모를 확인한다.
2. **수강생 예약 전화가 오면** 그 강사·교시 칸에 예약(등록 수강생) 또는 메모 예약(첫 방문·이름 모름)을 적는다. 강사가 정해지지 않았으면 맨 위 **미배정** 줄에 적는다.
3. **수강생이 오면** 시간표 칸의 [수업시작] → 수업 기록 저장.
4. **수업이 일찍 끝나면** [종료]. 그 칸에 [수업시작]이 다시 나타나 다음 수업을 시작할 수 있다.
5. **강사가 조퇴하면** 그 칸의 [조퇴].
6. **확인할 일이 생기면** 오른쪽 확인 필요 패널에 한 줄 적어 두고, 해결되면 체크한다.
7. **하루를 마치면** 업무일지 탭에서 그날 일지를 쓰고 [카톡 복사] → 단톡방에 붙여 넣는다.

## 3. 강사 탭

강사 탭 위쪽 메뉴: **날짜별 · 전체 달력 · 강사 관리 · 이름 검색**

### 3-1. 날짜별 보기 (시간표)

- [‹ 이전 주] / [다음 주 ›]로 주를 옮기고, 월 \~ 일 탭으로 날짜를 고른다. 날짜 선택 칸으로 바로 갈 수도 있다. 처음에는 오늘이 열린다.
- 표 = 강사 × 1 \~ 4교시. 이름 옆 "주"/"보조"는 역할 표시일 뿐이다.
- **표 머리 인원**
  - "총 6명 · 부족 2" — 그 교시에 출근 가능한 인원(고정 + 조건부). **8명 미만이면 주황색**으로 "부족"이 붙는다.
  - 그 아래 "고정 5 · 조건부 1 · 결근 2" — 고정 = 확정 근무, 조건부 = 올 수도 있는 강사("조"), 결근 = 원래 배치였는데 빠진 강사.
- 회색 칸 = 근무 없음(또는 조퇴 후). 입력할 수 없다.
- 표 아래에 그날 **빠지는 강사**와 메모가 나온다.
- **1분마다 자동으로 새로 불러온다.** 다른 매니저가 적은 내용이 보이도록 하기 위해서다. 글을 입력하는 중이거나 예약 창이 열려 있으면 기다렸다가 새로 불러온다.

### 3-2. 시간표 칸 사용법

칸 하나 = 그 강사·날짜·교시. 위에서 아래로 다음이 있다.

| 순서 | 항목 | 설명 |
| --- | --- | --- |
| 1 | **예약** | 누르면 큰 창이 뜬다. 등록된 수강생을 체크하고 [저장]. 칸에 "예약: 김철수"처럼 보인다 |
| 2 | 수업 기록 | 강의실 + 수강생. 강의실·수강생을 누르면 수정 화면 |
| 3 | 버튼 | [수업시작] · [추가] · [종료] · [취소] · [조퇴] |
| 4 | **메모 예약** | "메모" 입력칸. 미등록(첫 방문)·이름 모르는 수강생을 자유롭게 적고 **Enter**로 저장 ("박민수(첫 방문)", "3명") |

**예약 vs 메모 예약**

- 수강생 탭에 **등록된 수강생** → 예약 (수업시작할 때 미리 체크되어 편하다)
- 아직 **등록 안 된** 수강생, 이름 모르는 수강생 → 메모 예약
- 한 칸에 둘 다 적어도 된다.
- 메모를 지우려면 입력칸을 비우고 Enter. 예약과 메모를 한 번에 지우려면 [삭제].
- 그 칸에 **수업 기록이 생기면 예약·메모는 자동으로 숨겨진다.** 방문 회차에는 들어가지 않는다.
- 지난 교시 칸의 예약·메모는 고칠 수 없다.
- 결근 등으로 근무가 빠진 칸에 예약이 남아 있으면 "**근무 없음 · 확인 필요**"로 보인다 → 다른 강사에게 연락·안내한 뒤 [삭제]한다.
- 다른 매니저가 같은 메모를 먼저 고쳤으면 저장이 막히고 안내가 뜬다. 화면을 새로 고쳐 바뀐 내용을 보고 다시 적는다.

**버튼**

| 버튼 | 언제 보이나 | 하는 일 |
| --- | --- | --- |
| [수업시작] | 진행 중인 수업이 없는 근무 칸 | 강사·날짜·교시가 채워진 수업 기록 폼. 예약 수강생은 미리 체크됨 |
| [추가] | 수업마다 | 그 수업에 수강생을 더한다 (늦게 온 수강생) |
| [종료] | 지금 진행 중인 수업 | 지금 시각을 종료 시각으로 저장. 같은 칸에서 다음 수업을 시작할 수 있다 |
| [취소] | 수업마다 | 확인 후 그 수업 기록을 **삭제** |
| [조퇴] | 오늘, 아직 끝나지 않은 근무 칸 | 그 교시까지 근무하고 다음 교시부터 근무에서 뺀다 |

- 조퇴를 누른 칸에는 "조퇴" + [취소]가 보인다. 잘못 눌렀으면 [취소]로 원래 근무로 되돌린다.
- 지난 칸의 [수업시작]은 기록이 없을 때만 보인다 (수기 기록을 옮길 때 쓴다).

### 3-3. 미배정 줄

강사를 정하지 않고 "11/5 2교시에 오겠다"처럼 날짜·교시만 정한 수강생용. 시간표 **맨 위 "미배정"** 줄에 교시마다 예약·메모를 적는다 (근무 여부와 상관없음).

- 강사가 정해지면 **[배정]** → 그 교시 근무 강사를 고른다 → 그 강사 칸으로 옮겨진다. 그 칸에 이미 예약·메모가 있으면 합쳐진다.
- 미배정 줄은 강사와 연결되어 있지 않아서, 수업을 시작해도 **자동으로 숨겨지지 않는다.** 배정 없이 수업을 시작했다면 [삭제]로 직접 지운다.

### 3-4. 전체 달력

- 10/27 \~ 12/10 전체를 월 \~ 일 달력으로 본다.
- 날짜 칸에 교시별 총 인원(고정 + 조건부)과 강사 이름. 8명 이상 초록, 미만 주황. 조건부 강사는 노란 점선.
- 날짜를 누르면 그날의 날짜별 보기로 간다.

### 3-5. 이름 검색

- 위쪽 검색칸에 강사 이름을 넣고 [검색] → 그 강사의 일정이 날짜순으로 나온다 (확정 교시, "조" 조건부 교시, 메모).
- [✕ 닫기]로 검색을 끈다.

### 3-6. 강사 관리 (등록·수정)

- **강사 관리** → 맨 아래 "새 강사"에 이름·연락처를 넣고 [등록].
- 강사의 [수정]을 누르면 상세 화면:
  - **기본 정보**: 이름·연락처 → [저장]
  - **요일별 기본 배치**: 요일 × 교시마다 역할(주/보조/-)과 비고 → [기본 배치 저장]
  - **날짜별 예외**: 종류 · 시작일 · 종료일 · 교시(비우면 전 교시) · 메모 → [추가]

| 예외 종류 | 쓰는 경우 | 예 |
| --- | --- | --- |
| 결근 | 기본 배치인데 그날 못 옴 | 11/9 3교시 불가. 기간이면 시작일·종료일로 한 번에 |
| 조건부 | 확정은 아니지만 올 수도 있음 ("조"로 표시) | 11/16부터 전 교시 가능할 수도 |
| 추가 배치 | 기본 배치는 아닌데 그날만 확정 | 11/20 4교시 추가 |
| 메모 | 근무는 하지만 알아 둘 내용 | 12/2 오후 1시간 늦을 수 있음 |

- 잘못 넣은 예외는 그 줄의 [삭제].
- [강사 삭제]는 기본 배치·예외까지 모두 지워진다. 그만둔 강사라도 지난 수업 기록이 있으면 되도록 삭제하지 않는다.

## 4. 수업 기록

### 4-1. 폼 여는 방법

1. 맨 위 **[수업 기록]** 버튼 → 빈 폼
2. 강사 시간표 칸의 **[수업시작]** → 강사·날짜·교시가 채워진 폼
3. 수강생 탭 목록에서 체크박스로 수강생을 고르고 검색칸 옆 **[수업시작]** → 고른 수강생이 채워진 폼 (여러 명이면 한 수업에 함께)
4. 수강생 상세의 **[수업시작]**

### 4-2. 폼 항목

| 항목 | 설명 |
| --- | --- |
| 수강생 | 이름으로 찾아 체크. 여러 명 가능. 목록에 없으면 수강생 탭에서 먼저 등록 |
| 날짜 · 교시 | 지금 기준으로 채워진다. 바꾸면 강사·강의실 목록이 그 시점 기준으로 바뀐다 |
| 강사 | 그 교시 근무 강사만 나온다. 이미 수업 중인 강사는 고를 수 없다. 지난 날짜면 전체 강사 |
| 강의실 | 빈 교실이 배정 순서(일반 6개 → 상담실 → 창고 겸용)대로 자동 선택. 바꿀 수 있다 |
| 시작 · 종료 시각 | 비워도 된다 (비우면 교시 시간으로 본다) |

- **희망 강사 알림:** 수강생 1명에게 희망 강사가 있으면 "OO 강사님이 수업하나요?"가 뜬다. [예]면 강사가 자동으로 채워지고, [아니오]면 직접 고른다. 희망 강사가 모두 없거나 수업 중이면 안내만 나온다.
- 같은 강사·같은 교실에 겹치는 수업은 저장되지 않고 안내가 뜬다.
- "빈 교실이 없습니다"가 나오면 진행 중 수업 중 끝난 것이 있는지 확인하고 [종료]한다.

### 4-3. 지난 기록 옮기기

수기로 적어 둔 지난 수업도 날짜·교시를 바꿔 입력할 수 있다. 지난 날짜에서는 강사 목록이 전체 강사로 바뀐다.

### 4-4. 수업 기록 탭

- 최근 날짜순 목록 (날짜 · 교시 · 강의실 · 강사 · 수강생)
- 검색칸에 수강생 또는 강사 이름 → [검색]
- 행을 누르면 수정 화면. 아래 [수업 기록 삭제]로 지운다.

## 5. 수강생 탭

- **[+ 수강생 등록]** → 성명(필수), 연락처, 나이, 희망 수업, ID(출석 사이트 아이디), 수업 시작일, 희망 강사(여러 명), 비고 → [저장]
- 목록: 이름 · 방문 회차 · 희망 강사. 이름 검색 가능.
- 이름을 누르면 상세: 기본 정보, 방문 회차, 들은 수업(최근순, 회차 표시), [수정] · [삭제] · [수업시작]
- **방문 회차**는 수업 기록 수로 자동 계산된다. 직접 고치려면 수업 기록을 고친다.
- 수강생을 삭제하면 예약에서도 빠진다.
- 출석은 이 사이트가 아니라 **기존 출석 사이트**에서 한다.

### 5-1. 상담 탭 (상담일지)

- **[+ 상담 등록]** → 상담일(오늘로 채워짐), 성명, 연락처, 희망 수업, 희망 요일, 희망 시간, 비고 → [저장]. 성명·연락처 중 하나는 꼭 적는다.
- 전화·방문·홍보 같은 상담 방식은 비고 맨 앞에 "(전화) 월요일 9:30 방문 예정"처럼 적는다.
- 목록은 최근 상담일순. 이름·연락처로 찾고, **미등록만**을 체크하면 아직 수강생이 안 된 상담만 보인다.
- 이름을 누르면 수정 화면. 맨 아래 [상담 기록 삭제].
- 수강하기로 하면 그 줄의 **[수강생 등록]** → 수강생 등록 폼이 상담 내용으로 채워져 열린다. 나이·ID·희망 강사 등을 채우고 [저장].
  - 상담일·희망 요일·시간·비고는 수강생 비고에 "[상담 10/29] 희망: 매일 13:00"처럼 들어간다.
  - 저장하면 상담 줄이 **등록됨 · 이름**으로 바뀌고, 누르면 수강생 상세로 간다. 같은 상담을 두 번 등록할 수 없다.

## 6. 운영 매니저 탭

- **날짜별**: 주 이동 + 요일 탭. 그날 근무자·근무 시간, 휴무·시간 변경자를 본다.
- **매니저 관리** → "새 매니저"에 이름·연락처 [등록] → [수정]에서
  - **기본 근무표**: 요일별 시작·종료 시각 → [기본 근무표 저장]
  - **예외**: 날짜 · 내용(휴무 / 시간 변경) · 시간 · 메모 → [추가]

## 7. 업무일지 탭

- **[+ 업무일지 작성]** → 오늘 날짜로 열린다. 교시별 강좌 수와 신규·기존 수강생 수는 **그날 수업 기록으로 미리 채워져** 있다. 다르면 고친다.
  - 날짜를 바꾸면 그 날짜의 수업 기록으로 다시 채워진다. 이미 쓴 날짜면 그 날짜의 수정 화면으로 간다 (하루에 한 줄).
  - 신규 = 그날 처음 수업을 들은 수강생, 기존 = 전에도 들었던 수강생. 여러 교시를 들어도 1명으로 센다.
- 강사(출석 메모)·특이사항은 "- "로 시작하는 줄로 적으면 카톡에서 보기 좋다.
- 목록 맨 위에 누적 강좌·신규·기존·수강생, 작성한 날이 자동으로 나온다. 날짜를 누르면 수정 화면(맨 아래 [업무일지 삭제]).
- **[카톡 복사]** (목록의 줄마다, 수정 화면 위쪽) → "복사됨 ✓"이 뜨면 카톡 단톡방에 붙여 넣는다. 빈 항목은 빠진 채로 정리돼 있다.

---

## 8. 확인 필요 패널 (오른쪽)

- "확인할 내용"과 "관련 사람(선택)"을 적고 [등록].
- 해결되면 체크 → 목록에서 빠지고 아래 **"해결된 항목 (n)"**으로 옮겨진다.
- 해결된 항목을 다시 확인해야 하면 펼쳐서 [되돌리기].
- 잘못 쓴 항목은 [삭제]. 내용 수정은 없으니 해결 체크 후 새로 적는다.
- 패널 머리를 눌러 접고 펼 수 있다 (표가 좁을 때 접는다).

## 9. 자주 묻는 것

| 상황 | 할 일 |
| --- | --- |
| 수업을 잘못 시작했다 | 시간표 칸의 [취소] (또는 수업 기록 탭에서 삭제) |
| 수강생·강의실을 잘못 골랐다 | 시간표 칸에서 강의실·수강생 이름을 눌러 수정 |
| 수강생이 늦게 합류했다 | 그 수업의 [추가] |
| 조퇴를 잘못 눌렀다 | 그 칸의 [취소] |
| 강사가 갑자기 결근한다 | 강사 관리 → 그 강사 [수정] → 날짜별 예외에 "결근" 추가. 남은 예약은 "근무 없음 · 확인 필요"로 보이니 다른 강사로 옮기거나 수강생에게 연락 |
| 수강생이 수업 기록 폼 목록에 없다 | 수강생 탭에서 먼저 등록 |
| 원하는 강사가 강사 목록에 없다 | 그 교시 근무가 아니거나 이미 수업 중이다. 근무라면 진행 중 수업을 [종료]했는지 확인 |
| 내가 적은 메모가 사라졌다 | 그 칸에 수업 기록이 생겨 숨겨진 것이다 |
| 다른 사람이 적은 내용이 안 보인다 | 1분 안에 자동으로 보인다. 급하면 브라우저 새로 고침(F5) |
| 사이트가 열리지 않는다 | 서버 PC가 켜져 있고 검은 서버 창(`start.bat`)이 떠 있는지 확인. 그래도 안 되면 `운영 가이드.md` 7. 문제 해결 |

## 10. 주의할 것

- 서버 PC의 **검은 서버 창을 닫으면 사이트가 꺼진다.** 최소화만 한다.
- 수강생·강사 연락처가 들어 있으니 화면을 띄운 채 자리를 비우지 않는다.
- 삭제는 되돌릴 수 없다 (매일 22:00 백업에서만 복구 가능). 수업 기록·수강생·강사 삭제 전에는 한 번 더 확인한다.
